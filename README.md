# 🎮 GameZone India

A responsive browser gaming website built with HTML, CSS and JavaScript.

## Features

- Responsive gaming homepage
- Search games by name
- Filter games by category
- Individual HTML pages for each game
- No build tools or frameworks required
- GitHub Pages compatible

## Project structure

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Push the files to the repository's `main` branch.
2. Open repository Settings.
3. Open Pages.
4. Select Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.

Website:
https://anshnayak460-beep.github.io/-game/

## Notes

- Every game link on the homepage must point to an existing HTML file.
- Replace the placeholder email in `contact.html`.
- GitHub Pages hosts static files; server-side features need a separate backend.
